What gets published

  • Every spec, report, plan, or longer write-up becomes a live 42 Press page.
  • Posts use the Redaction typeface and the site's editorial layout.
  • Writing stays brief and readable at a high-school level.
  • Facts, numbers, recommendations, warnings, and source links stay intact.

Publishing loop

  1. Write the page in Markdown with a clear title, date, and short subtitle.
  2. Use plain words, short sentences, tables, and bullets when they save time.
  3. Publish it to the live site.
  4. Check the real page, including tables, visuals, mobile layout, and links.
  5. Return the verified page link, not a document file.

Mission Control

Refresh the dashboard when work starts, finishes, blocks, unblocks, or changes state. Use the exact product, file, or task name. Keep private details out of public notes.
